```
     폰 (브라우저)                        Supabase
  ┌──────────────────┐              ┌──────────────────┐
  │  React Native    │  RPC 9개     │  Postgres        │
  │  + react-native- │ ───────────▶ │  + RLS           │
  │    web           │              │  + Realtime      │
  │                  │ ◀─────────── │                  │
  │  미니게임 10종    │  방·세션 알림 │  서버 코드 0줄    │
  └──────────────────┘              └──────────────────┘
          │
          │  게임 도는 20초 동안 — 통신 0

    시드로 문제를 만들어 각자 진행
```

| 영역 | 선택 |
|---|---|
| 앱 | React Native (Expo) + TypeScript, `react-native-web`으로 웹까지 한 코드 |

| 서버 | Supabase (Postgres + Realtime + 익명 Auth) |

| 테스트 | Jest + `@testing-library/react-native` · 778개 |

## 의사결정 4가지

### 1. 시드 하나로 공정성을 만든다

**문제** — 10명이 동시에 같은 게임을 하는데, 문제가 다르면 불공정하다.
그렇다고 실시간으로 맞추면 술집 와이파이에서 끊긴다.

**결정** — 서버는 **시드 하나**만 내려준다. 각 폰이 그 시드로 문제를 만든다.
`Math.random()`을 쓰면 안 되고, 모든 무작위는 시드에서 파생시킨다.

**얻은 것 셋**
- 게임 도는 동안 **통신이 0이다.** 네트워크가 끊겨도 판이 끝난다.
- **10명이 병렬로 게임을 만들 수 있었다.** 게임끼리 서로를 몰라도 되고,
  공유 지점은 `registry.ts`의 한 줄뿐이다.
- 게임 담당자가 **네트워크를 몰라도 된다.** 혼자 하는 미니게임 만드는 것과 같다.

**대가** — 시드 결정성이 깨지면 즉시 불공정해진다. 그래서 PRNG를 가장 먼저,
가장 엄격하게 테스트했다.

---

### 2. 스토어를 접고 웹으로 갔다

**문제** — 술자리에서 "이거 깔아봐"는 절반이 안 깐다. 앱 설치 자체가 최대 이탈 지점이다.

**결정** — 플레이스토어 출시를 접고 웹 배포로 전환. 링크 하나면 브라우저에서 바로 들어온다.
안드로이드·iOS를 안 가린다.

**대가** — 푸시 알림이 어려워졌다. iOS는 홈 화면에 추가해야만 웹 푸시가 된다.
그래서 알림이 아직 미완이고, 이게 지금 가장 큰 남은 과제다.

---

### 3. 서버 코드를 한 줄도 안 썼다

**결정** — Edge Function도 서버 프로세스도 cron도 없다.
**Postgres 함수(PL/pgSQL) 9개와 RLS가 전부다.**

시간 판정도 서버 타이머를 안 쓴다. 서버는 `server_now()`로 **현재 시각만** 알려주고,
"게임할 시간인가"는 각 폰이 계산한다. 폰 시계는 몇 초씩 어긋나 있는 게 정상이라
서버 시각과의 차이를 재서 보정한다.

**얻은 것** — 배포·재시작·모니터링이 없다. 5명짜리 팀에서 아무도 서버를 안 봐도 된다.

---

### 4. 절대평가가 파장 곡선을 만든다

**결정** — 꼴찌가 아니라 **3판 평균 40점 미만**이 벌칙 대상이다.

**왜 이게 중요한가** — 상대평가면 아무리 다들 잘해도 매번 누군가 집에 간다.
절대평가면 취할수록 점수가 떨어지므로 **초반엔 아무도 안 걸리다가 후반에 자연스럽게 늘어난다.**

파장 곡선이 규칙 하나에서 저절로 나온다. 별도 로직이 없다.

1등도 미달이면 벌칙이고, 전원 미달이면 다 같이 집에 간다.
