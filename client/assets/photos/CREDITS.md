# 동물 사진 출처

전부 [Unsplash](https://unsplash.com)에서 받은 사진이다.

## 라이선스

[Unsplash License](https://unsplash.com/license) — 상업적·비상업적 이용 모두 무료이고,
수정·배포가 허용되며 **출처 표기 의무가 없다.** 그래도 찍은 사람이 있으니 여기 남겨 둔다.

금지 조항 두 가지는 우리와 무관하다.

- 무수정 사진을 파는 것 → 우리는 사진을 팔지 않는다
- Unsplash와 비슷한 사진 서비스를 만드는 것 → 우리는 술자리 게임이다

## 다시 받는 법

```bash
curl -o wolf.jpg "https://images.unsplash.com/photo-1588167056547-c183313da47c?w=900&q=80&fm=jpg"
```

받은 뒤 **얼굴이 가운데 오도록 4:3으로 잘라 800×600으로 줄인다.**
폰에서 두 장을 위아래로 쌓아야 하므로 세로형 사진은 그대로 쓸 수 없다.

**아웃포커스가 심한 사진은 쓰지 않는다.** 흐린 곳을 뒤집으면 얼룩이 생겨
"편집했구나"가 한눈에 보인다. 처음 넣었던 햄스터 사진이 그래서 빠졌다.

새 사진을 넣으면 `src/games/spotDiff/logic.ts`의 `PHOTOS`에 고칠 자리를 손으로 잡아 넣고,
반드시 아래로 확인한다.

```
npm run check:spotdiff
```

점수(얼마나 달라지나)와 선명도(그 자리가 또렷한가)를 같이 재서, 못 찾거나 얼룩지는 자리를 잡아준다.
